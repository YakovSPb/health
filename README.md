# Тренировка и питание

## Актуальный план тренировок

→ папка **[docs/](docs/README.md)**

- Неделя: **вт жим · чт ноги · сб тяга · вс футбол**
- Ротация схем A/B каждые 4 недели
- Фокус-дни при плато (например «Фокус: Грудь»)
- Каталог упражнений + трекер весов
- Импорт в Google Calendar: `docs/календарь/тренировки.ics`

Файл `план тренировки.odt` — старая версия (до правок с тренером), не использовать как основной.

## Питание

См. `Питание.txt` / `Питание-распечатка.docx` и трекер еды.
