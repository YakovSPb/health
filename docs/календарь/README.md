# Календарь

Файл [тренировки.ics](тренировки.ics) — импорт в Google Calendar на **~1 год** (29.09.2026 → ~21.09.2027).

## Импорт в Google Calendar

1. Открой [Google Calendar](https://calendar.google.com)
2. Шестерёнка → **Настройки** → **Импорт и экспорт** → **Импорт**
3. Выбери `docs/календарь/тренировки.ics`
4. Укажи календарь (лучше отдельный «Зал»)
5. Импорт

Если уже импортировал старый файл — удали старые события / календарь «Зал» и импортируй заново, иначе будут дубли.

## Что внутри (не бесконечно — на год)

Силовые: **18:00–19:30 МСК**. Футбол: **вс 10:00** (52 раза) — время игры поправь вручную.

| Что | Как |
|-----|-----|
| **Ротация A/B** | 13 блоков × 4 недели: A → B → A → … до сентября 2027. В названии события: `· схема A` / `· схема B`, в описании — список упражнений |
| **Фокус-дни** | 9 штук ~раз в 6 недель (см. ниже). В этот день обычная тренировка снята |
| **Напоминание ротации** | каждые 4 нед. пн |
| **Напоминание фокуса** | каждые 3 нед. пн |
| **Конец года** | ~27.09.2027 — обновить ICS |
