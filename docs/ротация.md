# Ротация схем A / B

Одни и те же упражнения → мышца адаптируется. Меняем **вариант снаряда/угла**, не цель дня.

## Как пользоваться

1. В [плане недели](план-недели.md) колонки A и B.
2. **4 недели схема A** → **4 недели схема B** → снова A (или новый набор C позже).
3. В [трекере](трекер-весов.md) отмечай текущую схему и дату старта блока.
4. Основные правила техники и ошибки — в каталоге; при смене схемы веса чуть снизь на 1–2 шага на первую неделю.

## Текущий блок

| Поле | Значение |
|------|----------|
| Схема | **A** |
| Старт блока | 29.09.2026 |
| Конец блока (через 4 нед.) | 24.10.2026 |
| Следующая | B (27.10–21.11) |
| Календарь | год вперёд: A/B каждые 4 нед. до ~09.2027 (`календарь/тренировки.ics`) |

## Что именно чередуем

| Мышца | Вариант A | Вариант B |
|-------|-----------|-----------|
| Грудь — база | Жим штанги лёжа | Жим гантелей лёжа |
| Грудь — верх | Наклон гантели ~30° | Жим сидя вверх (от тренера) |
| Грудь — изоляция | Бабочка | Кроссовер (две верёвки) |
| Плечи — жим | Рычажный тренажёр | Жим Арнольда |
| Спина — вертикаль | Тяга блока к груди | Подтягивания |
| Спина — горизонталь | Тяга сидя + гантель | Рычаг с упором в грудь + тяга сидя |
| Ноги — база | Присед | Выпады с гантелями в ходьбе |
| Бицепс | Штанга + добивка частями | Сидя одной рукой |

Изоляция (разведения, задняя дельта, сгибание ног, икры, трицепс на блоке) часто **остаётся** — менять можно реже (раз в 8 недель) или только хват/рукоять.

## Мини-смена внутри блока (если скучно или болит)

Не жди 4 недели: замени только одно упражнение на парное из B. Остальное не трогай — так проще сравнивать прогресс весов.
