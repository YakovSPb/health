# Питание

Дневник на телефоне: [zal.diabal.ru](https://zal.diabal.ru) (главная). Зал — ссылка «Зал» или `/zal.html`.

Исходный план порций: корневой `Питание.txt`. Каталог продуктов — из распечатки.

## Нормы

| Параметр | Значение |
|----------|----------|
| Цель дня | 2000 ккал, белок ~180 г |
| Поддержка (для дефицита) | 2900 ккал |
| Оценка веса | 7700 ккал ≈ 1 кг |

Дефицит дня = 2900 − съедено. Вкусняшка заложена в цель 2000, не сверху. Шаблон дня ≈ 1970 ккал.

## Меню по умолчанию

| Приём | Состав |
|--------|--------|
| Завтрак 08:00 | яйца 3 шт; курица **140 г**; овсянка 50 г сухих; клюква 10 г; лист **150 г**; миндаль 20 г |
| Обед 14:00 | курица **140 г**; макароны 60 г сухих + сыр **20 г**; огурцы+помидоры **200 г**; яблоко 100 г |
| Ужин 20:00 | творог 1% **300 г** + йогурт 2% **100 г**; киноа 50 г сухих + паста томатная **30 г**; капуста **150 г** |
| Вкусняшка | шоколад 70% 20 г (замена: пастила / мармелад) |

Овощи — у каждого типа своя порция (лист/капуста 150, морковь/перец 100, огурцы+помидоры 200). Один продукт в разных приёмах — одни граммы.
Добавки: макароны→сыр 20 г, киноа→томатная паста 30 г, творог→йогурт 2% 100 г (при ⇄ творога йогурт тоже).
Крупы — сухой и готовые. Капучино — «+ продукт → Кофе». Свободные ккал — кнопка **+ свободные ккал**.

Данные и шаблон: `zal/food-data.js`. Дни синхронизируются через `food-api.php` → `/var/lib/zal-diabal/food.json` (телефон и комп одно и то же). Локальный кэш: `localStorage` `food.diary.v3`.
