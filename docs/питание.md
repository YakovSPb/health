# Питание

Дневник на телефоне: [zal.diabal.ru](https://zal.diabal.ru) (главная). Зал — ссылка «Зал» или `/zal.html`.

Исходный план порций: корневой `Питание.txt`. Каталог продуктов — из распечатки.

## Нормы

| Параметр | Значение |
|----------|----------|
| Цель дня | 2400 ккал (−500 от поддержки), белок ~180 г |
| Поддержка (для дефицита) | 2900 ккал |
| Оценка веса | 7700 ккал ≈ 1 кг |

Дефицит дня = 2900 − съедено. При цели 2400 плановый дефицит 500. Вкусняшка заложена в цель, не сверху. Шаблон приёмов в сумме ≈ 1970 ккал.

## Меню по умолчанию

| Приём | Состав |
|--------|--------|
| Завтрак 08:00 | яйца 3 шт; курица **140 г**; овсянка 50 г сухих; клюква **20 г**; лист **150 г**; миндаль 20 г |
| Обед 14:00 | курица **140 г**; макароны 60 г сухих + сыр **20 г**; огурцы+помидоры **200 г**; яблоко 100 г |
| Ужин 20:00 | творог 1% **300 г** + йогурт 2% **30 г**; киноа 50 г сухих + паста томатная **30 г**; капуста **150 г** |
| Вкусняшка | шоколад 70% 20 г (замена: пастила / мармелад) |

Овощи — у каждого типа своя порция (лист/капуста 150, морковь/перец 100, огурцы+помидоры 200). Один продукт в разных приёмах — одни граммы; **свободные ккал** — свои в каждом приёме.
Добавки: макароны→сыр 20 г, киноа→томатная паста 30 г, творог→йогурт 2% **30 г** (при ⇄ творога йогурт тоже); кокосовое молоко Aroy-D **10 мл** (~19 ккал, 185 ккал/100 мл).
Орехи: миндаль 20 г / грецкие 18 г / кешью 22 г / **фундук 19 г** (порции ≈ по ккал).
Крупы — сухой и готовые; в каталоге также цельнозерновой хлеб (270 ккал / 10 г белка на 100 г). Капучино — «+ продукт → Кофе». Свободные ккал — кнопка **+ свободные ккал**; рядом с полем — калькулятор **+ − × ÷** (как в Diabal). Повторное нажатие кнопки в том же приёме открывает калькулятор, а не дублирует строку.

День изначально пустой: у каждого приёма кнопка **добавить шаблон** заполняет только этот приём из меню выше. При заполнении обеда завтрак сворачивается (и остаётся свёрнутым при следующем открытии); то же для ужина → обед. Клик по заголовку приёма — свернуть/развернуть.

Данные и шаблон: `zal/food-data.js`. Дни в `/var/lib/zal-diabal/food.json` через `food-api.php` (телефон и комп одно и то же). Локальный кэш: `localStorage` `food.diary.v3`. Свёрнутость приёмов: `food.ui.v1`.

Синк **мержит** дни: выкладка кода / смена каталога дневник не сбрасывает. Пустой день в файл не пишется. У сохранённого дня есть `updatedAt` — при конфликте побеждает более новый; без метки непустое не затирается пустым.
