# Трекер весов

Заполняй после тренировки. Сравнивай одинаковую **схему** (A с A, B с B).

**Обозначения:** одно число — сумма со грифом или вес блока/рычага; `N+N` — на каждую руку или сторону. Если у гантелей отмечена одна сумма (например 56) — в таблице пишем `28+28`.

Строки с пометкой **оценка** — старт для схемы B, не с зала; после первой тренировки B замени на факт.
