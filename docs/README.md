# Тренировки — навигация

Мужчина, 42 года, ~8+ месяцев в зале. Цель: сила и форма без ломания суставов. Воскресенье — футбол, ноги в этот день не качаем. Ограничения по анализам — в [здоровье.md](здоровье.md).

## Расписание (актуально)

| День | Тип | Содержание |
|------|-----|------------|
| Вт | Жим | Грудь, плечи, трицепс + изоляция |
| Чт | Ноги | Квадрицепс, задняя поверхность, ягодицы, икры |
| Сб | Тяга | Спина, задняя дельта, бицепс + изоляция |
| Вс | Футбол | Восстановление для зала; ноги не трогаем |

Кардио зоны 2 / бассейн / баня — по самочувствию в свободный день (пн, ср, пт) или коротко после силовой.

Старый файл `план тренировки.odt` — архив. Рабочая версия — эта папка `docs/`.
