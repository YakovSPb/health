# Планка / скручивания

**Группа:** корпус  
**Схема:** A и B (день ног)  
**Картинка:**

![планка](../_img/планка.png)

## Как делать
- **Планка:** 3×30–45 сек, корпус прямой, таз не провисает.
- **Скручивания в тренажёре:** 3×12–15, без рывка головой.
- На скамье 45° — максимум **одно** из упражнений до сильного жжения, не оба до отказа.

## Ошибки
- Два пресс-упражнения «до горящего живота» каждый раз
- Планка с провалом поясницы
- Тяга головой руками за шею
