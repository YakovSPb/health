# Сгибание ног сидя

**Группа:** ноги (бицепс бедра, изоляция)  
**Схема:** A и B  
**Картинка:**

![сгибание-ног](../_img/сгибание-ног.png)

## Как делать
1. Спина к спинке, валик над бёдрами прижат — таз не отрывается.
2. Нижний валик за лодыжками: сгибай ноги к себе, вверху короткая пауза.
3. Вниз медленно, без броска и раскачки корпусом.
4. После румынки — добивка бицепса бедра без осевой нагрузки.

## Ошибки
- Рывок тазом / отрыв от сиденья
- Слишком большой вес с раскачкой
- Полный «бросок» вниз
