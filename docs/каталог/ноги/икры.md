# Подъём на носки сидя

**Группа:** икры  
**Схема:** A и B  
**Картинка:**

![икры](../_img/икры.png)

## Как делать
1. Полная амплитуда вниз–вверх.
2. Пауза 1 сек вверху, не пружинить.
3. 12–15 повторов.

## Ошибки
- Только пол-амплитуды
- Отскок из нижней точки
- Огромный вес с читингом корпусом
